# 小白本地启动说明

更新：2026-09-05。本页只讲当前 Mac 上的开发环境，不代表生产环境已经上线。

## 现在是什么状态

- 根目录 `.env` 已设为开发环境，权限为 `0600`，不会提交到 Git。
- 付费模型总开关已打开：`ENABLE_PAID_MODEL_CALLS=true`。
- 火山方舟 Character 是默认角色模型，百炼 Qwen 是手动备用；不会同时调用。
- 专用 PostgreSQL 位于 `127.0.0.1:55432`，只监听本机。
- 专用 Redis 7.4 位于 `127.0.0.1:56379`，只监听本机；验证码和跨进程锁可以联调。
- 《孽岛疑云》资料仍在仓库外的 `private-data`，启动项目不会自动读取或上传正文。

**打开付费开关不等于马上扣费。** 只有玩家进入已发布剧本并触发真实角色模型请求时才可能扣费。打开页面、启动前后端、运行离线测试和数据库检查都不会调用云模型。

## 最简单的启动方法

1. 用 VS Code 打开 `ai-jubensha-fusion` 文件夹。
2. 点击“终端 → 运行任务”。
3. 先运行“测试：全部离线检查”。
4. 运行“手动启动：后端 127.0.0.1:8010（有副作用）”，按提示输入 `START`。
5. 再运行“手动启动：前端 127.0.0.1:3001（有副作用）”，同样输入 `START`。
6. 浏览器打开 `http://127.0.0.1:3001/play`。

后端任务会自动启动专用 PostgreSQL 和 Redis，并把数据库向前迁移到最新版，但不会清库或降级。也可以在“运行和调试”中选择“调试：前后端一起启动（本机开发）”；第一次使用时 VS Code 会提示安装推荐的 Python/Pylance/ESLint 扩展。

管理员登录后，可从用户菜单进入“来源材料核验”，或打开 `http://127.0.0.1:3001/admin/source-bundles`。当前已保存 483 份来源文件，页面用于查看材料和检查一致性，尚不能发布或启动此剧本。候选包最新迁移的真实数据库验收仍待执行，不能把迁移文件存在当作已应用。

如果出现连接失败，先看后端任务是否显示监听 8010、前端是否监听 3001；仅数据库/Redis 启动时页面仍不能工作。开发验收曾使用 8011 上的虚构 API，它只用于测试来源页面，不支持正常登录和游戏；验收结束后会关闭，正常前端应连接 8010。不要为解决连接问题清库或覆盖 `.env`。

新增管理员入口 `http://127.0.0.1:3001/admin/script-reviews`（用户菜单“剧本审核记录”）：查看已接收候选、核对来源标识、登记人工报告与问题处理历史。当前尚未导入真实《孽岛疑云》候选，空列表属于正常状态；新表需应用候选/审核迁移后可用。这里不会自动完成语义审核或批准发布。

## PostgreSQL 的三个安全按钮

VS Code 的“终端 → 运行任务”中有：

- “数据库：启动本地 PostgreSQL 55432”
- “数据库：检查本地 PostgreSQL 55432”
- “数据库：安全停止本地 PostgreSQL 55432”

它们只操作下面这套专用环境，不接触 Docker 历史库：

```text
~/Library/Application Support/AIJubenshaFusionTest/
```

“安全停止”只停止服务，数据库文件仍然保留，下次可再次启动。

## Redis 的三个安全按钮

VS Code 的“终端 → 运行任务”中还有：

- “缓存：启动本地 Redis 56379”
- “缓存：检查本地 Redis 56379”
- “缓存：安全停止本地 Redis 56379”

它们只操作 `~/Library/Application Support/AIJubenshaFusionRedis/`。Redis 固定绑定 `127.0.0.1`，不会暴露到局域网；停止前还会核对数据目录，避免误停其他 Redis。

## 当前边界

- 这套环境足够继续第一阶段和文字链路开发，但不是生产上线环境。
- 正式上线前还要把本机 Redis 换成生产托管/独立 Redis，并准备真实短信、域名/TLS、数据库备份恢复和监控。
- 《孽岛疑云》共确认到 717 个资料文件；要在 `/play` 中出现，仍需完成版本化导入、规则校验、人工审核并发布。付费开关不会替代这些步骤。
- 商业正文已经获得上云授权，但在导入链完成前，不会拿正文做随意冒烟测试；任何真实调用都继续受单局 Token 和人民币预算限制。

## 编译与模型审核任务（阶段 3C）

管理员菜单新增“编译与模型审核”（`/admin/authoring-jobs`）。选择已冻结来源中的具体文字文件，填写内容版本、人数后排队；页面展示任务阶段、模型检查问题和费用估算，并链接候选人工审核。排队本身不调用模型。

当前采用显式单任务 worker，运行方式及限制见[阶段 3C](PHASE_3_AUTHORING_WORKFLOW.md)。真实数据库需先按本页既有流程确认目标/备份并迁移，不能把隔离 SQLite 浏览器验收当成真实库已经升级。不要将完整《孽岛疑云》材料勾选后直接试跑：已有多原件归属、缺页和契约不能表达的规则仍需处理；单次输入有严格上限。

完成任务只代表编译/模型检查已执行，不能替代最终人工批准、运行时版本绑定或完整游玩验收。恢复不会重发可能已计费的未知调用。
