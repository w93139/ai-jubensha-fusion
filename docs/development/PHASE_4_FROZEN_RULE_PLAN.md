# 阶段 4F：冻结规则草案与原文摘录

针对 4D 三次模型混淆动作前置和材料前置，改为显式结构输入：管理员准备完整、带来源的 1.2 规则草案，任务冻结该输入，模型只能填写指定文本槽位。服务器从冻结草案装配候选，拒绝额外规则字段、槽位增删、重复、越界与非原文摘录；后续 Audit、人审及独立发布沿用原门禁。

草案只是待审核的输入，冻结不等于语义正确或人工批准。不能自动修改历史失败候选，也不能从烟测预期偷偷补规则。旧 1.1/1.2 编译任务及提示不升级。新请求显式携带 rule_plan，使用 authoring-model/1.3、bailian-authoring-json/1.3 与 compiler-text-draft/1.0；产物仍为 script-package/1.2。

本轮先实现新流程及离线对抗验证，不继续三次失败后的付费提示重试。不更换角色模型、不迁移数据库、不批准商业本；自然对白与完整结算仍为后续开发，runtime_ready=false。
