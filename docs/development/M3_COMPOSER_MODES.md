# M3 发言模式交付（2026-09-09）

用户要求：角色回答直接完整展示，发言板切换公开发言与单独对话，角色直接点选。

## 已实现

- 授权角色台词一次完整展示；取消逐行、播放等待和暂停/跳过操作。已授予回忆及收藏同步可用。模型生成本身仍需等待。
- 底部发言板提供“公开发言 / 单独对话”两项切换，切换栏固定在面板顶部。公私内容独立，切换不发送消息、不清空未提交草稿。离开当前局/账号仍清理草稿。
- 单独对话沿用现有双方可见的私聊、有限议题和阶段限制，公聊不转发私人内容。选择角色后开始对话，结束后可选其他角色；既有记录仍按对象查看。
- 角色使用横排点选卡，窄屏自动换行，提供选中标识和键盘焦点；公开回复、旧材料提问与调查建议中的选角同步采用卡片。
- 模式切换时停止正在进行的公开语音输入，避免识别结果进入错误模式。
- 结局已有私聊时可从“更多→单独对话”回看；只切换展示页，不改变游戏阶段。已结算不能新发消息。没有私聊记录时不显示该入口。

## 用户验收

1. 刷新原游戏页面，展开底部“议题 / 发言”，应看到“公开发言 / 单独对话”。
2. 写一段公开草稿但不发送，切到单独对话再切回，草稿应保留；私聊页面不展示该草稿。
3. 单独对话时直接点击角色卡，应立即高亮；点击开始对话，按当前可用议题交流，记录按双方气泡显示。
4. 收到角色回答后，应一次显示完整内容，收藏立即可用；不会再逐行打字。
5. 收起面板仍可浏览材料；手机宽度角色自动换行，模式始终位于面板顶部。
