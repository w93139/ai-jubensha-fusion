# 阶段 4N：引用目录接入编译审核任务

2026-09-06。本轮将 4M 的纯本地引用目录装配器接入显式 Authoring 1.12，包括请求、模型配置、任务快照、费用预占、worker、烟测入口和管理员工作台。AI 只选择已有引用，服务器确定目标与来源；仍不自动批准发布。

这是离线及模拟接线验收，供应商是否接受动态 schema、实际是否减少引用错误以及语义准确性均未验证。4L 的四次真实失败仍是原结果，本轮没有重发、回填或追加付费请求。

## 实现

新请求使用 `package_contract=script-package/1.2`、完整 `rule_plan`、`compiler_mode=CONFIRM_FROZEN_TEXT` 和 `audit_mode=CITATION_CATALOG`。新任务固定为 `authoring-model/1.12` / `bailian-authoring-json/1.12`。旧请求与旧任务保留原版本，不能交叉执行；HTTP 仍只排队，显式 worker 才能调用模型。

新增独立审核提示，保留五维覆盖、单真人调查规则、有限长度、COMPLETE/INCOMPLETE 和人工审核边界。线上的候选格式为 `citation-audit-draft/1.0`，最终领域报告仍为 `script-audit/1.1`。模型不填写自由目标 ID、来源定位或发现 ID；服务器严格复制所选目录项，不补来源，不删 BLOCKER。

静态模型快照保存提示及基础 schema 的哈希。每次 Audit 请求根据已冻结候选生成目录和动态索引上界，保存候选/目录绑定、动态本地 schema 哈希及实际供应商 response_format。目录和 schema 的全部 UTF-8 字节均纳入保守 token 上界与费用预占。持久账本从任务原 rule_plan 重建期望目录与 schema；即使篡改者重新计算外层哈希，也不能扩大索引上界、替换候选/目录绑定或套用其他版本。

实际调用前仍重新准备并逐项比较完整请求，先保存 IN_FLIGHT 再调用。未知用量保留预占并进入核对状态，不自动重发；已知格式失败保留费用、结束原因和安全位置。新增两个固定诊断码，只显示根位置或最多 10 条发现、每条最多 100 个引用的有界位置，不显示未知模型字段或原始错误文本。

工作台新建“固定正文”任务使用新显式模式，原任务继续按原版本显示。新提示说明真实模型效果尚待验证；选择模式本身不会发起模型调用。
