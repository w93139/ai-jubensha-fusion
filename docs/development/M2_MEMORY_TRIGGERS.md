# M2：实际事件触发私密回忆

## 本轮约定

目标：实际公开发言或角色取得指定线索后，按来源规则只向对应角色授予回忆；页面显示本人回忆，刷新后保持。AI 的内部输入可使用自己已经获得的回忆，不能公开原卡。

范围：显式 `script-package/1.3` 的回忆声明、结构/来源/人工问题定位、新规则引擎与既有文字试玩事件接线、私密回忆展示。旧1.0–1.2包、模型提示、历史binding和事件保持原样，无新数据表。新增版本仍经过现有发布门禁，不自动升级旧包。

不做：本轮不接自由自然对白、回忆转述任务完成、投票评分或语音；不扩展模型Compiler/Audit提示，新1.3尚不支持现有编译任务，正式发布仍须完整模型审核接线与人审，不能用开发夹具当批准。

完成条件：

- 回忆正文/接收角色/阶段下限/触发来源/原卡私密及转述义务均有严格声明；原文来源与编辑补充区分。
- 仅已保存的真人公开发言和已接受AI建议的实际短句匹配关键词；问题草稿、引用列表、自己念词、未来阶段内容不触发。按原文“提到”用字面包含，不使用可执行表达式或模型语义判断。
- 线索触发仅消费初始或本次事件真正新增的已获证据；既有私本、未获证据、回忆正文都不当作新的公开发言，不凭空递归触发。
- 每条回忆只授予一次，记录导致授予的事件序号与原因；重放同一日志一致，未知请求的重试不会重复授予。
- 人类视图仅显示本人的已获回忆，不泄露其他角色的回忆存在、触发词或数量。模型只读本角色已获回忆；原材料问答不能分享这些原卡。
- 源片段在私有隔离环境核对；商业全文、未决编辑规则和实际出版批准不进入测试样例。

验证：`backend/.venv/bin/python backend/scripts/test_fusion_security.py --disable-warnings`；前端既有八套组件测试、TypeScript、修改文件lint及构建；隔离浏览器发言/调查/刷新、390px和权限检查；按coding-workflow进行独立只读复核。

假设：当前单真人房间的已保存公开发言所有在场角色都可听到。原卡不可出示与可/必须转述分开存储；转述义务只展示，不能声称已自动履行。调查卡触发表示系统已将线索交给角色，不模拟人的逐字阅读。阶段前错过的发言不会在以后自动追溯触发。

## 本轮实际成果（2026-09-07）

`script-package/1.3` 增加有来源的回忆声明；`package-play-rules/1.2` 在已接受的发言、调查和线索分享之后确定性授予回忆。新的 `package-text-play-event/1.3` 把授予状态纳入原追加事件的重放与摘要，不新增表，也不修改旧会话绑定。

关键词只匹配实际公开短句。自己提到、问答草稿、引用正文、无效或过期 AI 结果、回忆正文中的另一个关键词都不会伪造触发。获得线索按实际接收者判断；AI 材料问答确实分享了线索时仍会触发相应回忆。每条只授予一次；前阶段已错过的发言不追溯。验证器另拒绝线索必定早于回忆开放且无法再次取得的声明，避免明确的触发死路；这不是整局可解性证明。

页面新增“我的私密回忆”：显示本人已获内容、发生在哪条记录以及可以/必须转述的提示。其他角色的私密回忆不返回页面；AI 调查输入只增加自己的已获回忆，公开引用和原文问答仍不能选这些原卡。没有原卡公开按钮；真人自由输入仍按角色说法保存，尚无任意文字的语义审查或自动转述完成判定。

来源核验及人工问题定位支持新回忆集合；候选仍不能绕过审核。**Compiler/模型 Audit 尚未支持 1.3，正式发布的 `MODEL_AUDIT_COMPLETE` 门禁仍阻止未审新包。** 不用测试夹具代替商业发布，不将此轮称为后台审核已修复。
