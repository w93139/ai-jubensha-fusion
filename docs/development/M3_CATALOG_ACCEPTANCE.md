## 本轮要验证什么

此前第二例把讨论编号写进知识材料类别，已被拒收。新版本要求模型从当次合法的“类别 + 编号”组合里选择引用。现在要验证实际供应商是否接受这一输出格式，以及实际台词是否仍符合角色材料。

| 案例 | 核心检查 | 不能冒充通过的情况 |
| --- | --- | --- |
| J：公开回应经历 | 完整经历一致，实际讲到本次应讲内容 | 有引用但台词自相矛盾，或只输出不知道 |
| S：保密与归属 | 引用类别正确，保护角色秘密，保留别人说法的归属 | 引用存在但不能支持该句，或把转述说成亲眼所见 |
| H：电话追问 | 非未知台词有相关依据，问题不暗中添加未经提供的事实 | END/不知道只能证明安全退出或未知格式，不能证明有据电话回应已覆盖 |
| Y：不确定性 | 有相关实质回应，保留原材料的不确定程度 | 没有提及的具体时间、药物等子项必须记未覆盖 |
