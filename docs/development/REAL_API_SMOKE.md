# 真实模型最小冒烟手册

这是给开发者执行的一次性接口检查，不是玩家功能。它只能发送代码内置的虚构角色“许岚”和虚构线索，没有文件、剧本、会话或自定义 Prompt 入口，因此不能读取《孽岛疑云》正文。

## 固定安全线

- 没有默认供应商；必须在命令中显式选 `volcengine_ark` 或 `aliyun_bailian`。
- 必须同时写出“允许一次付费请求”参数和人民币本地估算上限；上限不得超过 **¥0.01**。
- 每次进程最多调用一次；SDK 重试为 0，超时、限流和异常均不重发。
- 火山方舟固定 `https://ark.cn-beijing.volces.com/api/v3` 与 `doubao-seed-character-260628`。
- 阿里百炼固定 `https://dashscope.aliyuncs.com/compatible-mode/v1` 与 `qwen3.7-flash-2026-07-15`。
- 输出上限只有 96 Token，思考模式关闭，并使用严格 JSON Schema。
- 只从根 `.env` 提取所选渠道的 Key、地址、模型和计价项；不把另一家 Key 放入进程环境或客户端。
- 终端和收据不显示 Key、请求正文、模型回答、原始报错或原始请求 ID。
- 用量缺失或格式不对时，按最大预占费用记录并判定冒烟失败。

## 2026-09-04 实测结果

| 渠道与模型 | 结果 | 供应商用量 | 本地费用估算 | 整体耗时 | 请求/重试 |
|---|---|---:|---:|---:|---:|
| 百炼 `qwen3.7-flash-2026-07-15` | `passed` | 输入 160、输出 31、思考 0 Token | ¥0.0000568 | 2013 ms | 1 / 0 |
| 火山首次完整冒烟 | `safe_failure`，HTTP 404 | 未知 | 最坏预占风险 ¥0.0010944 | 未作为通过证据 | 1 / 0 |
| 火山完整冒烟复测 | `passed` | 输入 353、输出 35、思考 0 Token | ¥0.0003524 | 1283 ms | 1 / 0 |

这些请求都只发送内置 `synthetic_noncommercial` 虚构资料，没有发送商业正文。火山首次 404 未自动重试；随后控制台确认北京地域的模型已经开通，官方示例直接使用同一 Model ID、无需 `ep-...`，控制台所选 Key 与本地 Key 也一致。一个最小诊断请求先以输入 61、输出 5 Token 返回 200（约 ¥0.0000588，618 ms），随后上表的完整严格 JSON／关闭思考冒烟也返回 200。因此首次 404 记录为未能复现的历史临时异常；其用量未知时的 ¥0.0010944 仍不能写成已经扣费。

连同[核心服务纵向验收](LIVE_VERTICAL_SMOKE.md)，百炼已报告用量的本地费用估算合计 ¥0.0006078；本轮后续火山三次成功请求的已知估算合计 ¥0.0014784；两家已知合计 ¥0.0020862。若再计入首次火山 404 的最坏预占风险 ¥0.0010944，保守合计为 ¥0.0031806。联网前拒绝的纵向尝试 `request_count=0` 不计入合计。以上均是本地估算，不是云厂商账单。

## 执行前检查

1. 当天重新核对所选渠道的官方模型名、地域、价格与账户权限。
2. 确认根 `.env` 中所选渠道的 Key 有效，且对应计价版本不是占位值。不要把 Key 粘贴到终端命令。
3. 先运行离线安全测试；测试通过不代表真实渠道一定可用。

```sh
backend/.venv/bin/python backend/scripts/test_fusion_security.py
```

## 一次真实请求

在仓库根目录二选一执行。每条命令只验证一家；不会自动改用另一家。

```sh
# 火山方舟
backend/.venv/bin/python backend/scripts/real_provider_smoke.py \
  --provider volcengine_ark \
  --max-cost-cny 0.01 \
  --confirm-one-paid-call

# 阿里百炼
backend/.venv/bin/python backend/scripts/real_provider_smoke.py \
  --provider aliyun_bailian \
  --max-cost-cny 0.01 \
  --confirm-one-paid-call
```

脚本先用当前费率计算最坏费用；如果超过命令中的确认值，会在联网前拒绝。这个数是本地估算保护线，不是云厂商账户侧的绝对扣费封顶；真实账单仍以云厂商为准。完成后输出一条脱敏 JSON 摘要，并在被 Git 忽略的 `.runtime/real-api-smoke/` 中保存权限为 600 的脱敏收据，包含耗时、用量与费用估算。

`status=passed` 要求：实际返回模型与白名单一致、`finish_reason=stop`、用量完整、输出通过严格结构验证，且估算费用没超过确认值。其他情况都是 `safe_failure`：不输出原始内容，也不自动重发。

本冒烟的通过结果只证明对应渠道本次“Key／地域／模型／请求格式／用量字段”最小链路能工作；当前该结论已分别适用于上表的百炼与火山请求。它不代表真实剧本知识边界、角色质量、整局费用或 PostgreSQL 并发已验收。
