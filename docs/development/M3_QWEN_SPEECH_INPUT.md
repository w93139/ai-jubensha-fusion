## 任务契约

- 目标：现有公开发言语音入口可录制最长60秒，千问识别后先校对、追加原草稿，玩家手动发送；失败仍能输入文字及继续游戏。
- 范围：语音服务配置/HTTP适配、前端供应商说明、相关离线测试、本机受限真实验证和运行版本更新。角色对白模型及存档不变；不新增TTS、横屏、自动发送或自动供应商回退。
- 完成条件：现有百炼Key真实调用成功；正确解析录音文本；热词只取当前玩家视图中的角色姓名；同请求最多调用一次，取消/超时/过期不串稿、不重传、不重复扣限额；明确保留实体手机实录验收限制。
- 验证：`backend/.venv/bin/python backend/scripts/test_fusion_security.py`；仓库要求前端八套及语音/录音测试；`node node_modules/typescript/bin/tsc --noEmit --incremental false`；修改文件ESLint、预检和16项自测、`git diff --check`、隔离前端构建、独立只读审查、本机API及浏览器检查。
- 真实验证：使用本地生成的虚构中文测试录音，不使用用户麦克风或私本正文；总录音不超过180秒（按0.00022元/秒估算不超过0.0396元），每样本最多一次，新请求独立记录，失败不自动重传。仅凭合成录音不声称真人/方言/噪声准确率通过。
- 风险：现有Key的模型权限需实测；ASR输出可能误识别，必须保留校对步骤。密钥仅在服务器读取，不记录原始供应商错误。保留原豆包配置兼容路径，显式选择一家。
