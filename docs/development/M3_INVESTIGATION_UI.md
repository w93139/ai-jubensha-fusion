## 实现结果

1. 桌面“返回首页”移至吸顶栏左侧，手机替换顶部品牌入口为明显的“返回首页”，点击区域均至少44px；移除底部旧入口。
2. 固定左栏时共用左侧预留从56px变为376px，正文与底部输入一同避让。1024px以下使用每轮记录弹窗，避免挤窄正文；没有新增手机横屏功能。
3. “上一轮”打开当前已到达步骤的前一阶段资料及复盘，提供“回到当前进度”。首个阅读阶段无可回看项；不撤销任何调查或阶段事件，不产生模型调用。按回看解释实施，未收到撤销重玩的新增决定。
4. 收藏采用手机两列、宽屏三列索引，索引独立滚动且最多144px；一次仅展开选中的一条完整内容，支持本地关键词搜索。旧存储格式、收藏内容、权限解析和图片授权保持；预览沿用既有玩家正文过滤。
5. 图3文案来自未单独映射的HTTP409，可能是进度冲突，也可能是业务状态不允许；现有服务器日志不足以确定截图当次错误码。已区分明确revision冲突和其他409，统一“刷新进度”名称，在错误条及输入面板直接提供只读刷新。另阻止在其他请求未确认时提交新调查；公开发言未确认时明确“刷新→检查原发言”，主页面直接展示原请求核对入口。没有自动重发、删待定或改写旧回执。
