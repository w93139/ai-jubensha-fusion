# 阶段 3C：受控编译与模型审核任务

历史节点状态（2026-09-05）：工程实现与离线/浏览器验收完成，当时真实模型端到端未通过。前置为来源快照、候选 v1.1 和人工审核记录。后续完成[内容草稿与服务端固定字段装配](PHASE_3_COMPILER_ASSEMBLY.md)，并于 2026-09-06 通过[规则契约筛查与合成小样本真实闭环](PHASE_3_RULE_CONTRACT_REVIEW.md)，默认 Compiler v4 / Audit v3。下文保留本工作包前两次实测的原始结果；最新证据以该筛查记录为准，不代表商业整局或人审发布通过。

## 本工作包

管理员显式选取来源快照中的少量文字，提交持久任务；独立 worker 按 Compiler → 确定性校验及来源核验 → 候选落库 → 模型 Audit 执行。页面查询进度、费用估算、阻断原因与模型建议，并链接已有人工审核工作台。模型结果不创建人工批准，不授予发布权限。

每个任务冻结请求、材料投影、来源哈希、模型配置、价格版本、Prompt/Schema/请求契约。Compiler 只能原样提取所选且所引定位覆盖的正文；不填补缺页或推断多原件归属。文本单项 16 KiB、总计 48 KiB、最多 20 项，完整提示和 Schema 另受保守 32768 token 估计限制；超过即阻断，不截断。原件自动附带仅作为来源元数据，不把未读取图片宣称为已校对。

## 状态与事务

- 任务状态：QUEUED、RUNNING、NEEDS_RECONCILIATION、BLOCKED、COMPLETED、CANCELLED；步骤：COMPILE、CANDIDATE、AUDIT、DONE。
- 独立调用记录先预占，再持久化 IN_FLIGHT，才允许出网。每任务每模型步骤只有一条调用记录；最多一次 Compiler、一次 Audit，不自动重试或跨供应商回退。
- 短事务 CAS 与 300 秒租约保护步骤推进；等待模型期间不持有数据库事务或行锁。
- 未发送的预占可安全恢复。已发送但结果未知时停止并保留预占，需要对账；恢复接口不会重发未知请求。迟到结果可留作记录，取消任务不会因此继续推进。
- 候选通过既有幂等导入服务保存；崩溃后恢复复用已落库的输出和候选。输入、模型输出、收据和来源报告哈希在读取和消费时核验。

## 模型与预算

仅使用已适配的百炼固定 Qwen 型号，由配置白名单确认。创建任务不出网；worker 显式允许付费才执行。每次预占不超过 ¥0.05，每任务不超过 ¥0.10；SDK 重试为零，单次外层超时 90 秒。记录真实可用 usage 和按冻结价格估算的费用；未知 usage 保留预占，不能写成免费成功。费用是应用估算，账单以供应商为准。

Compiler 输出严格 CANDIDATE/BLOCKED 契约，Audit 覆盖来源、时间线、证据、知识边界、可玩性五维并绑定候选引用。两种模型输出都视为非可信数据。模型审核记录的来源为 MODEL，与已有人工审核记录分开。

## 验收计划

1. 离线验证来源筛选、编译输出、越权/编造拒绝、费用边界、异常脱敏。
2. 隔离 SQLite 文件数据库验证租约、并发 claim/dispatch、重复提交、取消迟到响应、崩溃恢复、篡改检测及迁移；不自动迁移用户数据库。
3. 测试真实路由权限、请求上限、无缓存和结构化失败；前端检查轮询清理、陈旧响应、幂等键、取消/恢复和移动宽度。
4. 完成整条模拟模型链后，使用完全虚构的小材料执行最多两次真实模型调用，总预占 ≤ ¥0.10。成功要求候选正文可定位原文、两角色两阶段及证据/真相完整、审核覆盖五维、usage/模型/契约符合限制。失败保留安全收据并如实报告，不循环付费修复。
5. 用隔离服务完成浏览器验收，随后关闭本任务启动的服务及浏览器空间。跑相关回归、类型检查和生产构建。

## 本轮不包含

真实《孽岛疑云》全量编译、OCR 逐页校对、最终人审发布门禁、运行时版本绑定、整局规则或语音。多原件归属未补全的真实材料仍会阻断；本轮成功仅说明受控小输入工程链成立。

### 首轮失败后的受控改进

先保留首轮原始收据及 v1 Prompt 文件，再加入只包含固定原因码和数组字段路径的 `output_diagnostics`，区分“正文不在已读材料”和“正文存在但不在所引范围”。不记录实体名、原文或供应商原始错误，也不回填首轮并不存在的诊断证据。

Compiler v2 将唯一 Markdown 标题列为服务端计算的 `available_locators`，优先使用这些可验证章节；重复标题不进入索引，完整索引计入输入和费用预占。仍需本地摘录/引用校验，不自动修复文本或放宽来源要求。纯文本行号定位仍按原规则，不能宣称本改动解决所有定位风险。v1 文件保留，新 Prompt 哈希使旧任务配置不再匹配，复验必须创建新任务。

阶段计划调整：在上述具体改动及离线回归完成后，只允许一次新版本的内置合成资料复验（最多 Compiler/Audit 各一次）；连同首轮一次调用，本工作包最多三次真实调用，累计最坏预占须 ≤ ¥0.10。此操作不是 worker 自动重试，不恢复第一轮已阻断任务；若仍失败则保留诊断，不继续循环付费调 Prompt。

### 已复现的来源空值误拒绝

离线用合法候选复现：输入来源省略 `page_count`、模型候选显式写 `page_count:null`，两者均通过来源 Schema，非空元数据也相同，却被原先原始 JSON 相等判断拒绝。已改为仅在来源绑定比较时，对双方做严格 `SourceFileV11` 解析并排除空值后比较；来源数组/原件数组的顺序、所有非空字段、文件哈希和路径仍须相等，未知字段及不合法补充来源照旧拒绝。

返回和保存的候选仍保留原始 null，原始包哈希不改写。其余根元数据继续严格相等。该修复由离线可复现案例支持，不能追认是第二次真实失败原因；修复后未再调用真实模型。
