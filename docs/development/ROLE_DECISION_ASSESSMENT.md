## 新增代码及边界

`role_decision.py` 新增纯角色视图与决策提议：先按角色和事件序号排除其他人私密与未来事件，区分 FACT/CLAIM 和说话者，独立提供本角色目标与合法选项。输出绑定上下文哈希，未知选项/事件引用、重复引用、额外字段和思考标签拒绝。所有输入必须来自服务端已授权状态；这个纯 helper 不是外部 API 鉴权器。

`role_decision_probe.py` 与 `real_role_decision_probe.py` 使用固定虚构场景做独立评估，预览冻结消息、配置、价格、schema、预算和外置评价标准；执行前校验摘要并保存不可重复执行凭据。每次调用前保存 IN_FLIGHT 和预占，未知用量停止并保留预占，不自动重试。评价标准没有进入模型消息。输出尚未广播、记入游戏票箱、触发回忆、扣调查点或揭晓答案。

后端离线专用入口 **1909 passed**，363 条已有弃用警告，32.96 秒；新增 16 项涵盖权限/未来过滤、固定 ID、上下文绑定、成本、请求前冻结、重复执行拒绝、未知用量与截断。前端未改，本轮没有重跑前端测试或生产构建。开发预检、自测与 diff 检查结果见本轮私有复核记录。

## 不能由本批证明的能力

- 六种是独立输入快照对照，没有上一条模型回答反复写回的长对话，也没有测长局遗忘或摘要偏差。
- 场景简单、目标明确，每种每家只跑一次；不足以判断复杂欺骗、说服、多角色关系、长推理或胜率。
- 全部决策任务都是调查，尚未验证主案指认和信任票；不以调查结果代替终局质量。
- 他人/未来哨兵未进入 Prompt，说明投影有效；模型未输出本人私密哨兵只说明本例未泄露，不保证所有自由台词安全。
- 引用合法不等于台词受证据支持；自然语言仍需独立评价和实际反馈，不能靠结构校验宣称不会幻觉。
- 本次没有修复或重测后台 Authoring/Audit 的旧失败，不能将角色选择通过当成后台审核通过。

## 开发决定

保持所选模型与非思考默认参数，开始 M2 的角色视图、公开陈述与正式决策分离接线；模型只提出选择，程序执行投票和状态变化。用户已同意按剧本固定核心规则、AI 依各自知识/目标判断、真人沟通影响判断的方向，不增设开局多套投票模式。

本轮不追加付费提示迭代。下一份可体验成果应是单阶段公共讨论与调查提议，补上不虚构新事实的台词质量检查和实际事件回写；再扩展集体表决、回忆与终局。具体平票/弃权/编辑规则仍需有依据的版本确认。自然台词未通过之前，不将本实验标为线上功能或已完成 M2；runtime_ready=false。
