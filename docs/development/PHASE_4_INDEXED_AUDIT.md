## 实现与边界

4G 中 Audit 的第二条发现 sources 字段不符合契约，被拒绝的原始值未保存。本轮没有猜测或修补该历史结果，而是新增 `audit_mode=TARGET_SOURCE_INDEXES`，仅与 `compiler_mode=CONFIRM_FROZEN_TEXT`、显式完整 rule_plan 和包 1.2 同时使用。新请求、模型快照和请求契约为 1.5；模型审核输出为 `indexed-audit-draft/1.0`。

模型收到按对象列出的来源目录，必须对每条发现选择至少一个自身来源的零基整数编号。服务器仅复制选中的引用，拒绝空列表、重复/越界/非整数编号、不存在的目标、直接传入 sources 和越权额外字段。不会默认补入全部来源或借用其他对象的来源。装配后仍走原 `script-audit/1.1` 的完整五维覆盖、目标和来源一致性校验，继续绑定候选、人审与发布依据。

工作台的“固定规则和正文，只检查内容”在创建新任务时选择 1.5；已有 1.4 任务保留其原提示和格式，不自动升级或恢复重发。HTTP 只排队，worker 仍需显式选择相同版本。模型没有规则修改权或发布批准权。接口与运行参数见[编号审核契约](../contracts/indexed-audit.md)。
