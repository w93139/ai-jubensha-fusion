# 阶段 4E：规则与来源逐项核对

2026-09-06，编码前范围。4D 三次真实 Compiler 的材料前置映射未通过固定合成验收，本阶段不再重复调提示或重发失败任务。先把失败转化为可核对证据，再决定后续编译策略。

## 本次行为

管理员在已有审核页选择候选和来源快照后，可分页读取阶段预算、调查动作和材料开放条件，并查看它们各自声明的来源段落。候选、快照与读取结果必须绑定；损坏文件、错误快照或过期候选拒绝返回。只读请求不创建来源报告、人工报告、批准、发布或模型调用。

当材料要求的公开证据已经是其直接前置动作的必要条件时，列为“可能重复，需对照原文”。这只是确定性结构提示：原文可能确实声明了独立条件，不能据此自动删除、自动判定语义错误或认定无提示的规则正确。图片、超出限额、重复标题等无法完整展示的情况必须明确标注，不能伪造原文。

在新的模型调用收据中补充解析前响应内容摘要，保留历史收据原字节与哈希，不记录私本原文。该摘要用于排查响应与本地解析，不证明供应商行为或模型准确性。

## 验证与边界

用独立虚构来源验证重复条件提醒、独立条件保留、准确引用范围、分页和截断、来源损坏拒绝、管理员隔离以及全部读取无写入。页面检查候选/快照切换、过期响应、错误提示、原文惰性文本显示和窄屏。原 1.0/1.1 审核及发布流程保持。

本阶段不自动修改候选、不放宽 4D 验收、不更换项目模型、不代表新 1.2 真实 Compiler→Audit 已通过。固定版本游戏继续由服务端执行；自然对白、完整计分和语音仍待接线。
