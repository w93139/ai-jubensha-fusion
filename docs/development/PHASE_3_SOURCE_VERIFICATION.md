# 第三阶段 A｜来源冻结与核验

2026-09-05。依据用户指定的《AI Agent 产品 Vibe Coding 通用技术栈手册 V2.1》、现有产品约束和第二阶段候选包。本工作包已完成来源冻结、核验接口和管理员页面；后续 Compiler、Audit、人审发布与运行时接线仍未完成。

## 目标与适配

把用户指定素材保存为可追溯的私有来源快照，检查丢失/篡改/错误类型/越界路径，令候选包来源校验绑定这份快照；在既有 Next.js 增加管理员材料查看入口。让产品经理能看见材料范围与边界，作为后续 Audit、人审和发布门禁的输入。

沿用 Python 3.13、FastAPI、Pydantic、Next.js Pages Router、现有 `/api/admin/fusion` 路径。大型原图留在仓库外文件存储；manifest 和核验报告采用有版本的 JSON、内容哈希、原子写入及读取复核。现有候选包仍使用 PostgreSQL，本工作包不迁移数据库。增加 Pillow（约束 `>=12,<13`，锁定 12.3.0）用于解码和校验原图格式，避免只按扩展名判断文件；未引入 OCR 模型。不执行来源中的脚本、提示词或嵌入指令。

本阶段没有新增模型调用契约；按手册第十节的纯工程阶段规则，不机械重复付费冒烟。默认角色对白模型和已验证契约保持既有决定。自动化使用虚构文件；真实素材只在本机核验与私有存储，不送模型。

## 范围与数据流

本机明确的选取计划 → 有界读取与真实类型检查 → 原子保存内容快照和 manifest → 管理员查看/核验 → 候选包引用匹配及可定位检查 → 私有核验报告。

源目录保持原样。快照默认放在仓库外 `private-data/import-jobs/source-bundles`，后端可用 `FUSION_SOURCE_BUNDLE_DIR` 指定受控目录；API 不接受任意目录、路径或外部 URL。快照与核验记录由完整哈希寻址，目录权限 0700、文件 0600。

这条链不批准发布、不自动运行 Compiler/Audit、不修改旧 `scripts` 表或在玩会话。文件内容一致不等于 OCR 正确、剧情合理或材料齐全；候选包仍须通过运行时兼容、Audit 和对应哈希的人审。

## 验证计划与验收入口

- 离线：文件缺失/篡改、软链接/路径穿越、类型伪装、上限、原件对应、重复冻结、损坏记录、跨剧本绑定、来源定位、权限与响应脱敏。
- 集成：用真实选定目录生成私有快照并核验；启动仅用于本阶段验证的回环服务，检查 HTTP 认证、来源列表/文本/原图读取与核验；不把 SQLite 或隔离服务说成生产部署。
- 前端：沿用既有管理员身份，新增 `/admin/source-bundles`；检查加载/无数据/错误、按需预览、文本安全显示、过期请求丢弃，类型检查和 ESLint。
- 产品经理验收：打开材料入口，确认版本和选取范围；查看一份分阶段材料及对应原图；核验结果显示文件一致，同时仍列出材料局限。核验不会把剧本放入公开大厅。

## 实现契约和操作入口

| 入口 | 行为 |
|---|---|
| 本机 `backend/scripts/source_bundle.py ... freeze` | 显式输入目录和选取计划，冻结到私有目录；HTTP 不提供任意路径导入 |
| `GET /api/admin/fusion/source-bundles` | 管理员查看版本摘要，损坏清单标记为 CORRUPT |
| `GET /api/admin/fusion/source-bundles/{bundle_hash}` | 查看此版本选取说明、文件元数据及原件关联 |
| `GET /api/admin/fusion/source-bundles/{bundle_hash}/sources/{source_id}` | 校验哈希和格式后按需读取，文本惰性显示、禁止缓存；仅允许快照内 ID |
| `POST /api/admin/fusion/source-bundles/{bundle_hash}/verify` | 核验所有文件并持久化报告，不批准发布 |
| `POST /api/admin/fusion/script-packages/{version_id}/verify-sources` | 请求体 `{ "bundle_hash": "完整哈希" }`；核验已存候选的实际包哈希、剧本、文件和定位引用 |
| `GET /api/admin/fusion/source-verifications/{report_hash}` | 读取并复核历史报告完整性 |
| `/admin/source-bundles` | 管理员用户菜单中的“来源材料核验”；选版本、搜索、文字/原图预览、跳转关联原件、查看问题文件 |

单文件最多 16 MiB，单快照最多 256 MiB / 1,000 文件，原图最多 4,000 万像素；软链接、非普通文件和格式伪装被拒绝。文本定位支持行号范围或精确 Markdown 标题，单张图片只支持 page=1；不假装支持 PDF 分页。候选 v1 无法完整表达编辑补充和多原件归属时，明确返回阻断问题。

现有导入任务的 `pending_gates` 尚未消费来源报告。报告是绑定包哈希的历史核验收据，既不是签名审批，也不是可直接使用的发布凭证。后续发布门禁必须重新核对当前文件、包哈希、校验器版本和对应人审；更改输入后旧报告不能替代新核验。本阶段文件处理在线程池运行，尚未实现持久化后台任务和中断续跑。
