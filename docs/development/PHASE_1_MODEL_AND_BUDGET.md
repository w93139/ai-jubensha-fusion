# 第一阶段技术开发文档｜模型适配与费用闸门

状态：预算、收据与双供应商适配已通过离线验证；真实 PostgreSQL 双连接预算锁已通过，百炼与默认火山均已通过核心 `FusionGameService` 纵向链技术验收。事务失败/重启恢复、HTTP 页面、人工口吻与商业整局仍未验收，因此第一阶段尚未最终验收。证据分别见[离线记录](PHASE_1_OFFLINE_VERIFICATION.md)、[PostgreSQL 记录](POSTGRES_BUDGET_INTEGRATION.md)、[直连冒烟](REAL_API_SMOKE.md)和[核心纵向验收](LIVE_VERTICAL_SMOKE.md)。

## 一、阶段目标

### 交付范围

- 把角色对白模型从“模板里写了名字”变成可核验、可冻结的运行配置。
- 普通对白显式关闭思考，确保内部推理不会进入公开台词或未来 TTS。
- 每次调用模型前先预占本局额度，多名 AI 同时发言也不能一起越过上限。
- 对成功、格式失败、超时、取消、崩溃、迟到结果和重复请求建立可恢复记录。

### 阶段产物

- 模型配置、请求参数、结构校验和安全降级实现。
- Token 与人民币预算判定、预占、结算和对账实现。
- 持久化调用收据及旧数据兼容规则。
- 使用虚构数据的离线测试、已执行的 PostgreSQL/真实模型最小验证记录，以及尚待执行的恢复、HTTP 页面和人工验收方案。
- 不含密钥和商业正文的配置说明、验收步骤与交接记录。

### 验收标准

- 无 Key、未开启付费开关或费用配置不全时，模型网络调用次数为零。
- 并发请求先共享同一局预算，再决定是否调用；重试、未知用量和迟到结果不会被当成免费。
- 模型输出、错误、日志和公开事件不包含内部思考、密钥、完整 Prompt 或商业正文。
- 第一阶段的离线实现、独立 PostgreSQL 并发验证、真实模型冒烟三类证据分别记录；缺少后两类时不能宣布第一阶段最终验收通过。

### 明确不做

本阶段不导入或改写商业剧本正文，不实现具体剧本的专属玩法，不建设版本化导入与发布链，不接语音，也不部署。

### 本阶段打通的主链路片段

```text
玩家合法动作
→ 读取该角色的授权知识
→ 事务内检查历史用量和在途预占
→ 写入系统收据并释放数据库锁
→ 调用模型，或因安全条件不足而零调用降级
→ 重新锁定并结算实际或保守用量
→ 只公开仍然有效且通过校验的角色台词
```

- 依据：[技术适配声明](TECHNICAL_ADAPTATION.md)。
- 本阶段采用：现有 FastAPI、Pydantic、SQLAlchemy、PostgreSQL、Next.js 和 TypeScript，不更换基座。
- 本阶段启用：持久化调用收据、预算预占、租约恢复和脱敏模型配置快照。
- 本阶段偏离：保留 Python 3.13、`/api/fusion` 和隔离离线测试入口；不套用新项目的 Python 3.11、SQLite、`/api/v1` 或全量 pytest 默认做法。
- 本阶段暂缓：正式前端扩展、导入、Audit、发布和语音。用户已单独批准本轮虚构资料最小付费验证：百炼与默认火山的直连和核心服务纵向链均通过；火山首次 HTTP 404 未重试并作为历史保留，后续完整复测通过。用户随后明确授权将本机正常 Fusion 付费开关打开；专用冒烟 CLI 仍使用独立确认参数。
- 开发路径：纵向切片，复用现有 `/play` 与 `/api/fusion`；本阶段主要改后端，不另做临时页面。
- 材料范围：用户已允许商业正文发送给所选官方云模型，但许可不等于技术条件就绪。在版本化知识包、阶段回忆和最小授权投影完成前，正文仍不进入 Git、离线测试、日志或真实 Prompt，也不据此宣称支持商业本整局游玩。

## 三、技术栈与模型

- 后端：Python 3.13、FastAPI、Pydantic、SQLAlchemy。
- 前端：Next.js 16、React 19、TypeScript；本阶段不增加 UI 依赖。
- 数据库：生产目标为 PostgreSQL；离线单元测试可使用内存 SQLite，但它不能证明多进程锁正确。
- 默认角色对白：火山方舟 `doubao-seed-character-260628`，北京地域 OpenAI 兼容 API。当前白名单只接受这个模型名；若账户要求推理 Endpoint ID，须先更新代码白名单、配置模板和离线测试，不能只在 `.env` 中换值。
- 显式手动备用：阿里百炼固定版 `qwen3.7-flash-2026-07-15`。它同时是未来 GM 总结候选，但当前没有已完成、已验收的 GM 模型链路。
- 路由原则：每局第一次模型动作冻结 provider、model、地址指纹和价格版本；已有局不能中途切换。第一阶段不做自动跨供应商 fallback，避免同一份角色资料在错误、拦截或超额后未经判断被发送两次。
- 角色对白思考固定为 `disabled`，没有环境变量可以打开；未来 GM 如需思考，须走独立任务契约和输出预算，内部思考仍不得公开。
- 两家虽然都兼容 OpenAI Chat Completions，思考参数并不相同：火山方舟使用 `thinking.type`，百炼使用 `enable_thinking` 与 `preserve_thinking`。普通对白均显式关闭思考；两家的当前请求形态都已由本轮虚构资料实测通过，后续正式调用前仍须依据官方文档和账户配置复核。
- Fusion 角色任务关闭 SDK 自动重试；重试只由本项目控制，避免重试次数和费用相乘。只对连接/超时、429 和 5xx 临时故障重试；400、401、403、404、截断、过滤和格式错误不会自动重复发送正文。
- 火山方舟使用 `max_tokens`，百炼按当前兼容接口使用 `max_completion_tokens`。百炼的调用前预占额会在配置上限外再保留 16 Token，以覆盖官方说明的最多 10 Token 输出浮动；任何非正常结束都不会公开为台词。
- 本阶段不新增第三方依赖，不引入 RAG、OCR、任务队列、对象存储或语音 SDK。

| 任务 | 第一阶段路由 | 自动切换 |
|---|---|---|
| 角色实时对白 | 火山方舟 Character（默认） | 禁止 |
| 手工 A/B 或受控备用测试 | 新测试局显式选择百炼 Qwen 固定版 | 禁止 |
| GM 总结/结构化推理 | 百炼为候选；链路尚未实现和验收 | 不适用 |

官方核验入口：[火山方舟模型列表](https://docs.volcengine.com/docs/82379/1330310)、[火山方舟 Chat API](https://docs.volcengine.com/docs/82379/1494384)、[火山方舟深度思考参数](https://docs.volcengine.com/docs/82379/1449737)、[阿里百炼 Qwen3.7 Flash 模型卡](https://help.aliyun.com/zh/model-studio/qwen3-7-flash)、[百炼 OpenAI Chat 兼容接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[百炼深度思考参数](https://help.aliyun.com/zh/model-studio/deep-thinking)。

## 五、项目结构

- `backend/src/fusion/providers.py`：两家供应商的模型、地址、密钥变量名、价格前缀和请求参数白名单；不保存密钥。
- `backend/src/fusion/agents.py`：模型配置、Prompt 版本、请求参数、有限重试和安全降级。
- `backend/src/fusion/budget.py`：Token 估算、费用计算、预算判定和未知用量保守结算。
- `backend/src/fusion/service.py`：事务内预占、持久化收据、租约、结算和迟到对账。
- `backend/src/services/llm_service.py`：允许 Fusion 单独关闭 SDK 自动重试，不改变旧 Agent 默认行为。
- `backend/tests/fusion_security/`：使用虚构角色、虚构线索和 fake client 的离线测试。
- `.env.example`：只记录占位配置，不保存真实 Key 或真实账单。
- `docs/development/TECHNICAL_ADAPTATION.md` 与本文件：记录适配决定、阶段边界、验收方法和未测范围。

## 六、数据、资产与状态

本阶段不新增商业正文资产。只在已有游戏会话和系统事件中保存脱敏预算快照与调用收据。

### 会话预算快照

每局第一次模型动作在 `GameSession.state_data["_llm_budget_v1"]` 冻结一份 JSON 对象：

| 字段 | 类型 | 含义 |
|---|---|---|
| `policy.schema_version` | 整数 | 当前为 1；用于识别预算结构 |
| `policy.token_limit` | 非负整数 | 本局 Token 上限 |
| `policy.cost_limit_cny` | 十进制字符串或空 | 本局人民币上限；空表示付费调用不放行 |
| `policy.*_rate_cny` | 十进制字符串 | 输入、缓存输入和输出费率 |
| `policy.paid_calls_enabled` | 布尔值 | 本局是否允许真实调用 |
| `policy.pricing_version` | 字符串 | 价格日期、渠道和账户档位 |
| `model` | JSON 对象 | provider、模型、Endpoint 指纹、Prompt 哈希、思考模式、超时、输出上限和最大尝试数；不含 Key、正文或完整 Prompt |
| `baseline` | JSON 对象 | 冻结前已有用量；Token 为非负整数，费用为十进制字符串 |

同一局中途修改模型或价格环境变量会触发安全阻断，避免旧局突然换模型或价格。需要新配置时，应创建新的测试局。

### 调用收据

每个 `AI_TURN_RECEIPT` 是 `SYSTEM_TRUTH` 可见性的系统事件，`schema_version` 当前为 2：

| 字段 | 类型 | 含义 |
|---|---|---|
| `source_event_id`、`character_id` | 整数 | 本次回答绑定的玩家动作与 AI 角色 |
| `current_generation_id` | 字符串或空 | 当前有效尝试 |
| `generations` | JSON 数组 | 历次 generation；历史不覆盖 |
| `generation_id` | 字符串 | 单次生成标识 |
| `lease_until` | 非负时间戳 | 运行租约到期时间 |
| `reservation` | JSON 对象 | 调用前预占的输入、缓存输入、输出、思考 Token 和人民币费用 |
| `accounting` | JSON 对象 | 供应商报告用量，或无法确认时的保守估算 |
| `status` | 受控字符串 | generation 的执行状态 |
| `accounting_status` | 受控字符串 | 未调用、供应商已报告、保守估算或超预占等结算状态 |
| `model` | JSON 对象 | 脱敏模型配置版本 |
| `response_model`、`finish_reason` | 字符串或空 | 核对实际模型与是否正常结束；不匹配、截断或过滤时不公开台词 |
| `provider_request_id` | 字符串或空 | 截断后的供应商请求标识，供后台对账；不进入玩家事件流 |

Token 字段使用非负整数；人民币费用在权威收据中使用十进制字符串，已有 `estimated_cost` 浮点字段只作为兼容展示汇总。

### 状态转换

| 当前状态 | 触发条件 | 下一状态 | 处理 |
|---|---|---|---|
| 尚无 generation | 配置完整且预算允许 | `RUNNING` | 先写预占和租约，再释放锁调用模型 |
| 尚无 generation | 付费配置不全或预算不足 | `BUDGET_BLOCKED` | 不调用模型；记录系统原因并使用安全降级台词 |
| `RUNNING` | 回包有效且游戏状态仍有效 | `COMPLETED` | 结算用量并公开通过校验的台词 |
| `RUNNING` | 回包时阶段或会话已失效 | `STALE` | 只结算，不公开台词 |
| `RUNNING` | 已有更新的 generation | `LATE_RECONCILED` | 只对账，不覆盖新结果 |
| `RUNNING` | 本地取消且确定未调用 | `CANCELLED` | 结束租约，不增加未知费用 |
| `RUNNING` | 取消时可能已被供应商接受 | `CANCELLED_UNKNOWN` | 按保守值暂记，等待对账 |
| `RUNNING` | 租约过期且用量未知 | `EXPIRED_UNKNOWN` | 按保守值暂记，允许后续新 generation |
| 任意结算 | 供应商报告超过预占 | `ACCOUNTING_OVERRUN` 结算标记 | 记录超额并阻止本局后续模型调用 |

结算状态从 `PENDING` 进入 `PROVIDER_REPORTED`、`ESTIMATED_MAX`、`NOT_CHARGED`、`NOT_CALLED_BUDGET` 或 `ACCOUNTING_OVERRUN`；未知用量不能转换成零费用。

### 恢复与兼容

- 旧会话没有预算快照时，从已有会话汇总和历史收据生成基线；若付费模式下旧用量无法核验，以 `LEGACY_ACCOUNTING_UNVERIFIED` 阻断调用。
- 旧版单 generation 收据只做兼容读取，后续安全写入时转为保留历史的 generations 结构，不丢弃旧记录。
- 快照、预占或结算字段缺失、类型错误、费用为负或状态未知时，不把它们强制变成零；标记为计费记录异常并停止本局模型调用。
- 服务重启后以数据库收据和租约恢复，不依赖内存变量。租约过期先做保守结算，再允许新的 generation。
- schema 升级时增加新版本读取器和迁移测试；旧局继续绑定原快照，不能原地套用新的模型或价格。

公开游戏事件只保留允许玩家看到的角色台词与安全状态，不公开系统收据。

## 七、API / 工具设计

本阶段不增加公开 API，也不允许模型调用文件、数据库、Shell 或发布工具。受影响的既有接口如下：

| 接口 | 请求与校验 | 成功结果 | 安全失败 |
|---|---|---|---|
| `POST /api/fusion/sessions/{session_id}/actions` | 已认证用户提交受控 `type`、`payload` 和 `idempotency_key`；先校验会话、角色、阶段和幂等 | 返回既有统一状态结构；合法提问或阶段推进可触发 AI 回答 | 非法游戏动作沿用 400/409；预算不足或付费配置不全时零调用并产生安全降级结果；计费记录损坏时返回不含内部数据的 409 |
| `GET /api/fusion/sessions/{session_id}/events?after={event_id}` | 校验用户属于该会话，并按事件游标查询 | 只返回该用户有权看到的事件 | `AI_TURN_RECEIPT` 等系统收据始终过滤，不因调试需要对玩家公开 |
| `/api/fusion/ws/{session_id}` | 沿用受保护的连接认证；令牌不得进入公开日志 | REST 动作完成后广播 `STATE_UPDATED` 与授权事件增量 | 连接失败只返回安全错误；广播中不包含系统收据、内部思考或预算明细 |

调用顺序固定为：认证 → 会话与角色归属 → 请求校验和幂等 → 阶段与知识权限 → 事务内预算预占 → 事务外模型调用 → 事务内结算和状态复核 → 授权响应。

预算阻断的详细原因只进入系统收据，不伪装成角色知道的事实。面向玩家可以使用中性的降级台词；后台错误也不能包含 Key、完整 Prompt 或商业正文。

当前角色回答仍是有超时上限的请求内操作，并通过 WebSocket 广播结果。如果真实冒烟显示耗时已经不适合稳定的 HTTP 请求，本阶段不能假装通过；应先更新文档，再改为持久化任务加状态查询，或由受控 WebSocket 工作流承载。

## 八、Prompt 设计

- Prompt 保存在 `backend/src/fusion/prompts/player.md`，内容哈希作为运行版本。
- 角色：只扮演当前会话分配的一个角色，不充当主持人、管理员或全知审计器。
- 输入变量：该角色身份、当前阶段可见事件和玩家问题；这些内容都视为不可信游戏数据，不能改变系统权限。
- 知识边界：模型只收到该角色当前允许知道的投影，不收到整本真相、其他私本或系统收据。
- 输出格式：只允许 `{"message":"...","action":"speak"}`；后端负责严格解析和校验。
- 禁止内容：额外字段、空白或超长台词、`<think>`、`reasoning_content`、工具指令、内部异常和系统预算原因。
- 格式合法仍不代表剧情语义正确；具体剧本的披露规则、证据逻辑和 Audit 属于后续阶段。

## 九、验收界面或纵向切片

- 本阶段不新增界面。现有 `/play` 是正式纵向切片，不平行创建临时页面。
- 离线实现先由自动化测试判断；真实角色表现必须在开发者准备的虚构测试局中，由产品经理亲自查看。
- 预算阻断当前使用中性降级台词；更清楚的运营提示以后单独设计，不能把系统内部原因说成角色知识。
- 在开发者提供安全的本地测试地址前，产品经理无需启动服务或配置端口。
