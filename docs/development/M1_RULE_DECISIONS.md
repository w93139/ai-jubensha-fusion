# M1 玩法采用记录

这份清单解释第一版完整文字游戏采用的玩法，不含案件答案。2026-09-07 已核对原始规则、修订记录及独立来源报告。用户随后明确回复“三项都按推荐方案”，下列A/B/C推荐方案已获采用；保留其他选项仅供追溯。本次是玩法采用，不是正式内容发布批准。

## A. 使用哪份内容

**建议：采用明确标注的修订版。** 原素材缺少49号卡，使用现有编辑补卡49-R，与50号卡同次获得，不额外消耗调查额度。补卡增加一条调查线索，不冒充找回的原卡，也不单独证明关键身份或时间。采用已有时间算术、索引和别名修正。

同时采用修订版的结局冲突处理：共同当晚事件先于个人后续，相关冲突分支按互相信任、单向信任、支持人数依次判断。保留案件真相，但部分投票组合会得到与原稿不同的结局。

执行细节采用修订表：每轮额度独立，第一轮剩余不结转；按表逐项扣调查/抉择费用，钥匙发现后共享且不消耗，重复读取及无效动作不扣费；回忆关键词只兼容已列明的写法，不自由猜测近义词。这些编辑细化需逐条保留来源，不把整篇修订稿归为原作。

另一种选择是坚持原作复原：需继续寻找原卡，并解决原稿重叠结局如何裁定，暂时不能保证无人主持自动跑完整局。

## B. 谁决定调查，怎样投票

**建议：一真人、四AI各一席。** AI根据自己听到的对话、看到的线索和角色目标独立决定，真人的沟通会影响它们的判断；程序不强行安排全员好结局。

- 调查按多数决定；最高票并列时由轮换席在并列项中选择。轮换只在一次新调查或抉择实际解决后推进。
- 全体主动同意跳过才跳过；若全部交来的票都无有效选择且非全体主动跳过，采用合法最小编号。模型失败或没有回执仍等待处理，不能当作主动弃权。
- 阶段结束不赠送未调查的资料，不跳过第二次私读。
- 终局每席提交主案指认、最多一张给其他在场角色的信任票，以及独立答卷；可以明确弃权，全部锁定后公布。主案指认范围可包括本人和非玩家人物，固定至少3票才算多数，弃权不降低门槛。
- 主案票在封卷后按本版身份归并规则合计，具体关系届时揭晓；信任票始终按五个玩家席位分别计算，不做这种合并。
- 采用修订版的目标解释：保护他人、避免被指认这类目标只检查本次主案的正式指认。原目标“无论杀害谁”的范围因此缩小；旧案仍在答卷中判断和计分。玩家目标说明须同步改清楚。
- 信任票限0–1张且不可投自己，所以某些人的圆满结局不能同时达成。

可改选“调查由真人拍板”：AI提供建议，终局仍独立投票，并采用上述明确票制。这样更容易掌控节奏，但属于单人适配，改变原本少数服从多数的调查规则。

## C. 答卷与评分

**建议：结构化答卷、自动分项给分。** 将人物、行为、原因及依据分开填写或选择，提供明确“不确定”；题目只用适当阶段可见的人物和中性选项，不能把真相当作提示摆出来。

- 保留31项目标及各角色原满分，采用现有修订版的主案5个1分、专属题2+2+1等部分分方案。
- 程序依据经核对的答案与证据组合计分；角色模型不能自己宣布得分，随便引用线索也不能获得证据分。
- 会影响隐瞒任务和结局的事实判断都进入明确的封存字段，包括有此效力的投票理由。其余自由补充文字只用于复盘，不偷偷改变得分。
- 显示每人的得分、本人满分与分项依据。原稿有最高分比较，推荐版只展示个人成绩，不据此另设唯一冠军。
- 玩家明确选择“不确定”可按确定细则不给该题正确分；系统没有标准答案、尚未判定或没有收到提交，都不能冒充玩家答错。

另一种选择是保留原作自由文字答卷、整项给分和最高分比较。须额外建立并验证可靠判卷方式；在此之前，含混答案可能需要人工复核，无法承诺每局立即完整自动结算。
