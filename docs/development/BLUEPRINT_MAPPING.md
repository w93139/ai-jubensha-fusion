## 不直接照搬的实现

- s02/s03 的命令黑名单、交互式 `input()` 审批不是游戏对象授权；使用服务端身份、局、剧本、角色和阶段校验。
- s08 的全量对话归档不能变成所有角色共用的记忆；先授权投影，再裁剪或摘要，底层事件保留其原始权限。
- s11 的进程内 daemon 线程不等于持久任务队列；s16 的本地 journal 不等于数据库事务、完整 JSON Schema 或费用硬上限。
- s17 判断器只读已有证据，不是测试框架或人工审核替代品；模型判断不拥有发布权。
- 不照抄参考项目的 Python 3.10、Anthropic 配置与 `setup.sh`。以本仓库锁文件和依赖清单为准，不在打开编辑器时自动安装、启动服务或调用模型。
