# M3 豆包语音输入

用户于本轮要求在玩家发言阶段加入豆包语音转文字。该要求更新了此前文字MVP的输入范围；TTS朗读、自动发言、自动请求角色回应与M4换角色仍不在本轮范围。

## 任务约定

- 在公开发言、向角色提问及电话私聊的文字输入处提供“语音输入”。点击后明确申请麦克风，显示录音时长、停止转写与取消。最长60秒，离开输入场景、切换账号/角色/阶段/通话或页面不可见时停止并丢弃在途结果。
- 音频仅由后端代理送豆包ASR。浏览器密钥不可见，页面不显示Token或费用；不得套用ARK文字密钥。官方录音极速API一次请求返回结果，前端采集单声道16kHz/16位PCM WAV，后端验证格式、长度与权限。
- 停止后显示可编辑识别稿，由玩家点击填入当前草稿；原稿保留，玩家发送后才进入原公共/私聊账本及内容审核。录音与转写不授予回忆、不调用角色模型，不把ASR次数计作角色互动轮数。
- 不自动录音/重传，不用浏览器自带厂商不明的识别服务回退。重复提交须幂等，未知结果不自动重发；受限调用与后台时长账本独立于已冻结游戏事件。录音不落盘，不向ASR传剧本或角色私本。
- 项目当前未发现独立语音凭据。已请用户将已开通服务的语音API Key配置到根.env，开发及离线验证继续；缺凭据时明确显示不可用，不能把模拟结果称作真实豆包识别。

## 完成标准

前后端接线、音频限制、账号/局/场景隔离、取消与资源释放、草稿并发修改、重复点击、错误和未知结果有针对性测试；必需的后端安全套件、前端测试、类型/lint、预检16与构建通过。独立复核及真实浏览器验证录音控件和权限/不可用状态；凭据到位后做受限真实转写，保留费用/次数证据，不使用用户私本作为测试内容。

更新本机验收页前备份并核对存档，旧冻结模型和事件不改写；后端按既有授权同步私有GitHub新标签。交付可操作验收流程，仍停在M3用户验证。后续思考强度建议极高，录音生命周期、隐私、异步身份和费用需要一起核对。

## 官方依据

- [豆包大模型录音文件极速版识别API](https://www.volcengine.com/docs/6561/1631584)：固定flash端点、独立语音鉴权、资源ID、WAV和同步结果。实际项目限制收窄到60秒。
- [MDN AudioWorklet](https://developer.mozilla.org/docs/Web/API/AudioWorklet)、[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)：麦克风显式授权和安全上下文；本机回环入口可使用，部署需HTTPS。

## 实现与验收记录（2026-09-08）

- 三个输入框使用同一控件和 AudioWorklet 录音器。原音频不落盘，WAV只含单声道16kHz PCM16；单段0.2–60秒。后端接口GET能力、POST一次识别、GET按请求收据；请求绑定当前账号/局/revision/channel/通话。
- 识别稿可返回至多6000字符供修改；合入现有草稿时仍要求总计不超过1000 Unicode字符。最终原提交动作才触发游戏写入与跑题/资料权限审核。
- ASR使用独立SQLite时长账本，默认每局1800秒、全服务每日3600秒，北京时间日界线；失败/未知派发也保留预占时长。UUID重复提交不二次派发，网络未确认仅手动查询原收据；文本约10分钟后清理。
- 根.env示例有语音专用配置，真实.env未改写。本机隔离服务仅白名单读取ASR配置，并挂载新路由和定时清理；旧冻结模型/预算元数据保持。当前配置缺失、功能关闭；不能将代码完成描述为真实语音验收通过。
- 独立复核修复了旧按钮回调借新会话串入识别稿的问题（scope及不可变本地会话ID双绑定），以及缺少crypto.randomUUID时打开控件的异常；关闭后恢复按钮焦点。全部Important已关闭。
