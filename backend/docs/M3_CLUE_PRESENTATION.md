# M3 线索呈现与跨阶段主持修复（2026-09-09）

目标：玩家只看到有用的线索标题和正文，已授权图片默认正向阅读；跨阶段顶部始终只有一个主持提示入口。

范围：玩家文本渲染、轮次摘要/索引、开场和游戏图片展示、顶部组件标识。冻结剧本、图片字节、原始编号、已存事件、角色权限、模型输入、费用和规则不变。编辑来源仍在后台保存，补充卡不冒充原版49号卡。

实现：显示时将补充卡的修订编号和版本/新增/非原卡元信息去除，保留地点标题；共用规则只去版本前缀，后续公开规则完整保留。扫描当前150项角色知识/线索/回忆，仅两项的编辑头改变；叙事里的引用、正常编号和限制词保留。收藏和阶段摘记共用相同显示处理，不回写历史内容。

图片：逐张目视核对55张已登记图，15张需要90/180/270度调整。默认方向绑定原图SHA256，不按跨剧本可复用的visual ID匹配；其余40张保持正向。授权请求仍在原角色/材料范围内，浏览器读取后校验图片指纹；等待指纹时账号变化或组件卸载则丢弃结果。卡面和放大窗口使用同一已授权本地图片及方向，取消直接打开未调整原图的新窗口。支持适应窗口/放大细节、内部滚动和关闭回位；不引入远程图片代理或图片生成服务。原扫描图中的纸张纹理与透视保持，不改变卡面文字。

重复主持根因：PlayHostHints与PlayPhaseAdvance是相邻组件，却同时使用pageScope作为key；React跨阶段重建时遗留旧主持组件。现分别使用host-hints:和phase-advance:前缀。真实ReactDOM虚构五阶段重渲染复现修前1→2→3→4→5，修后每阶段均1；不以静态字符串检查代替跨阶段行为。

工程验证：前端完整463项通过；类型检查无错误；源代码lint无错误，33条既有警告；专用后端2711项及预检16项通过。独立只读审查无阻塞/重要问题，另独立运行6项针对检查，核对全部55图指纹与15方向映射。本地生产构建及最终页面验收结果记录在本轮验证报告。放大细节的最后尺寸调整，另补做针对测试、类型/lint和生产构建。

用户验收：刷新原游戏，横向翻到补充线索，应只看到地点标题和线索正文；已取得的倒置/横置卡默认正向，点开放大仍同向且可读；继续下一阶段经过复盘选择后，顶部主持按钮始终只出现一次。旧存档直接生效，不需要重新开局或重新搜证。

下一轮：停在M3等待用户反馈，本轮不进入M4。根据线索阅读、阶段推进反馈修复复验；真实豆包ASR及实体手机软键盘验收仍按既有待办保留。建议开发思考强度高，重点是显示来源、跨阶段组件生命周期及既有存档。
