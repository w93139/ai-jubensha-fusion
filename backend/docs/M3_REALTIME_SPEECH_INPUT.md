# M3 实时语音转写

2026-09-10，用户要求实时转写，沿现有千问接入改为边录边传、边说边显示。完成本机验证后停等用户测试。

## 任务契约

- 行为：公开发言显式开始录音，展示累计定稿和当前句修订；停止后校对、追加原草稿、手动发送。单次最长60秒。
- 范围：千问流式适配、已授权HTTP签发短期一次性连接票据、WebSocket录音通道、独立时长账本、录音PCM回调、前端预览与相关测试。
- 不改角色模型/剧情规则/存档，不加TTS或横屏；不自动重连、重传、跨供应商回退或发送游戏发言。
- 连接权限：票据由原HTTP身份和本局权限验证后签发，30秒有效，只在首个WS消息传输，绑定发起Origin/局/阶段/频道，数据库原子消费。服务器持有供应商Key，固定北京WSS端点；WebSocket不直接依赖仅处理HTTP的认证中间件。
- 限额：两种ASR共用账本；实时开始先预占60秒，终止后按实际尝试传输帧数结算，至少0.2秒；崩溃无法结算时保留预占。每账号仅一条PENDING；每个UUID最多派发一次。
- 实时校验：连接开始完整验证游戏投影，随后每个片段/文字发送前查询本局owner、冻结binding_hash及最新不可变事件revision/hash；任一改变立即作废。避免每64毫秒重放整局而阻塞音频发送。
- 失败：清晰定稿可作为标记“转写中断”的待校对内容；未定稿部分不冒充完整结果。取消/切账号/局/阶段/后台停止采集及连接，不串稿；已有文字草稿保留。
- 验证：后端禁网安全全套、前端必需八套及语音/录音/实时通道测试、TypeScript、修改文件ESLint、预检及16自测、独立只读审查、隔离构建、本机API/浏览器验证、既有数据库行与模型绑定保持。
- 真实验证：使用上一轮虚构合成音频，最多180秒、每条新任务单次调用；流式标准价0.00033元/秒，估算上限0.0594元。重点证明停止前已有结果、句子修订不重复、最终完整文本、停止/断连；合成输入不代替实体手机。

## 实际结果

2026-09-10 实时转写已更新本机。用户点击开始录音后分段传输PCM、逐句替换临时文字，停止后校对并追加原草稿，仍手动发送；最长60秒。故障提供回执核对，保留服务器已定稿部分，不自动重连或重发。

- 最终检查：后端2858、前端389、TypeScript、修改文件ESLint、预检与16自测、隔离构建、三次独立只读复审通过；修复WS的HTTP依赖链、未定稿伪成功、麦克风/收尾失败无法取回文字及长存档重放堆积。
- 真实服务：3次虚构合成录音流式请求均完整返回，全部停止前收到非空文字，总音频21.146375秒。按0.00033元/秒估算约¥0.00697830；这是本地音频时长估算，不是供应商账单。
- 浏览器：实际游戏应用→票据→WS→后端→千问完成2条合成PCM流；桌面及390px能看到实时文本、终稿校对及原草稿追加，未发送游戏发言；测试草稿已清理。390px无横向溢出，模拟拒绝麦克风显示友好反馈。
