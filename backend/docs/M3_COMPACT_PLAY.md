# M3 紧凑阅读与横向卡片（2026-09-09）

目标：固定顶栏合并重复导航，降低常驻占屏；每轮记录收进左侧窄竖列，悬停展开且支持点击、键盘和触屏；发放线索以叠放卡组左右翻阅，答案选项先横排后换行。

范围：仅前端布局和阅读交互、PRD/交付记录。保留全部授权素材、图片读取、收藏/手记、选项顺序和单多选约束、原阶段及已保存操作。无后端运行逻辑、规则、模型、API/费用配置或数据迁移改变。

完成标准：桌面默认顶栏两行、不重复三排菜单；主操作右上、任务/回忆可随时打开。轮次列只含已到阶段，悬停进入记录面板不闪退，点击可固定，Esc可关闭；手机有等价点击入口。卡组能滚动/左右按钮/方向键翻阅，长文可完整阅读、图片与收藏可操作，不将未获线索加入卡组；切换账号/局不保留其他局内容。答案按原始顺序从左到右、从上到下排，窄屏至少两列，长选项换行且选择上限不变。

验证：前端全部离线组件检查、类型/lint、隔离生产构建；专用后端离线检查及预检/自测；独立只读复核；实际桌面/窄屏/横屏的导航高度、悬停/点击/关闭、卡组滚动、图片/收藏、答卷顺序与选中约束。重启只替换前端构建，不重启后端。比较旧存档行及调用账本，更新私有GitHub文档版本。

状态：已实现并部署本机验收候选。M3待用户验收；M4/正式发布未开始。真实ASR与实体手机软键盘仍待配置或设备验证。

工程验证：后端专用离线2711项通过；前端主体443项通过，最后焦点与层级修复25项定向通过，TypeScript与lint零错误（全源33条既有警告），26页隔离构建通过。独立复核发现并闭环横向坐标偏移、Portal点击/Escape后丢焦点、侧栏被输入框遮挡三类问题。
