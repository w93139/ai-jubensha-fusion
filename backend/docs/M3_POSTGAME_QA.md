# M3 结局答疑与玩家文案

2026-09-09｜PRD 0.14｜M3收尾。

- 主持弹窗改用玩家语言，去掉“第三档仅…”等后台约束解释。保留查看答案前的简短确认，避免未结束时误揭晓。
- 结局只逐行隐藏明确标记的编辑条件/衔接说明，不吞掉单换行相邻的真实剧情。原始剧本、判分和结局条件仍存后台。
- 已结束游戏顶部为“结局答疑”。用户点选问题，再显示一项主持解释。现有三个有源终局问题覆盖主案还原、贺先生托付的孩子、多次昏睡原因。
- 答疑目录来自当前角色绑定的已审内容，仅同终局阶段、三级明确答案范围加入；只返回题目和答案。未揭晓（包括全员封卷但未结算）不返回。
- 沿用有限议题设计，不开放任意文字/语音提问、生成式回答或现实建议，无关或敏感请求不能进入回答流程。剧情中的案情/身份说明不扩展为现实医学、暴力或隐私建议。这不是通用敏感词分类器；未来若开放自由提问，需另行实现服务端语义审核与拒答，不能以这次预设选项替代。
- 点选、关闭、换问题、重读均不改事件/分数/预算，不调用模型。切换局/角色清空所选答案；旧局读新展示即可。

验证：470项前端、2718项后端、类型/lint/隔离构建及预检；独立审查包含误删单换行正文的回归。实际部署、角色边界、手机弹窗和旧存档检查见本机 postgame-qa-20260909/final-report.json。工程通过与用户确认分别记录。

验收：刷新原结局 → 确认无编辑条件 → 点右上“结局答疑” → 逐个查看问题 → 关闭后继续阅读。未结束游戏保持主持提示，不显示结局答案。
