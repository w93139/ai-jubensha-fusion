# Fusion 基座升级记录

本记录是实现交接，不是 PRD。当前只升级现有 Next.js / FastAPI / PostgreSQL
基座，不更换技术栈，不导入或改写任何商业剧本，不安装 book-to-skill。

## 已实现

- `RoleKnowledgeView`：按本局、剧本、AI 角色筛选公共及本人私有事件，并加载已获得的证据。
  先过滤再取最近窗口，不把真人私有事件当公共历史；不把客观 `is_murderer` 标签送给 AI。
- 事件可见性明确允许 PUBLIC / 本人 CHARACTER_PRIVATE；SYSTEM_TRUTH、未实现的
  MURDERER_ONLY 和未知值默认拒绝。角色摘要不是授权来源。
- 真人和 AI 共用搜证候选范围，隐藏证据和未知地点证据默认不可搜索。
  这不是已经实现自定义解锁条件；隐藏证据只有后续明确实现规则后才能发放。
- 动作幂等键绑定操作与参数；客户端不能占用 AI 内部键。同一问题的 AI 回答绑定已接受的
  QUESTION_ASKED 事件，不再使用调用方重传的角色或文本。
- AI 领取记录与结果落库，重复请求不会重复生成；正常取消立即释放领取，进程硬崩溃后
  相同请求可在 600 秒租约过期后重试。不是自动后台重试队列，远端模型已计费但本地未记账的崩溃窗口仍存在。
- 模型等待期间不持有会话行锁。返回时复核会话、角色与阶段；跨阶段旧回答丢弃。
  同阶段普通聊天不会使正在生成的回答失效。PostgreSQL 写路径使用行锁；离线测试不能证明真实多进程锁行为。
- 玩家台词使用独立 prompt 文件和严格 JSON 契约，有界重试、失败降级；记录已返回的
  失败重试用量，不把 SDK 错误、内部推理标签或任意 JSON 对象直接展示成台词。
  这是格式与执行边界检查，不是能证明“永不剧透”的语义 Audit。
- REST 与 Fusion WS 都发送过滤后的完整本次事件增量，修正 WS 只推最后两条的遗漏；
  会话状态可 JSON 序列化，非法 WS 动作返回错误而不是直接中断整个连接。
- `/play` 的公开线索与未公开个人线索分区显示，默认折叠；公开后的自有线索不重复展示。
- 旧全本编辑、模拟器、历史/回放接口及旧 `/api/ws` 收口为管理员；普通玩家使用
  `/api/fusion` 与 `/play`。公开目录只列 PUBLISHED 且 is_public 的剧本。
- 旧编辑接口及编辑 Agent 的剧本信息仓储写入不能直接 PUBLISHED/is_public=True；
  仍需走管理员 Fusion 发布入口。API 状态补齐 REVIEW。该入口目前仍是基础校验，尚非完整人审版本门禁。
- `ENABLE_MEDIA_FEATURES=false` 同时阻止旧 WS 初始化 TTS 管理器，避免只关 HTTP 路由却继续合成语音。

## 与 agent-blueprint 的关系

采用 s02/s03 的受控操作与执行前授权、s04 的运行记录、s06 的独立角色上下文，
并借鉴可恢复步骤与输出校验的思想。不复制 shell/任意文件工具、全局共享记忆、工程团队或整套 CLI。
当前窗口裁剪不是 s08 的完整压缩器；AI 领取记录不是完整 s16 导入工作流；没有部署 s17 自动目标循环。

## 当前能力边界

| 用户目标 | 现状 |
|---|---|
| 角色信息隔离 | 本批修复了上述明确路径；还需实际对局及发布版本测试 |
| 不自爆、合理解释 | 已收窄输入和输出；没有完成逐条事实/披露策略审核 |
| 按规则主动分享、AI 推理投票 | 仍有旧 ID 启发式，未替换为剧本规则或证据决策 |
| 回忆解锁、条件搜证、扣时、多目标结算 | 尚未接入《孽岛疑云》的结构化规则 |
| 卡住时分级提示 | 尚未实现，不由角色模型临时编造答案 |
| 语音 | 旧 `/game` 有整段 TTS；新 `/play` 未接通，未实现 ASR、实时流式语音或真正打断 |
| 模型选型 | 保留当前 DEEPSEEK_* 接入，未换供应商，未发起付费评测 |
| OCR→Compiler→校验→Audit→人审发布 | 尚未完整实现，本批没有导入正文 |

旧普通用户管理/历史/回放页面会收到 403，管理员功能与历史数据保留。
客户端失败后重新点击会生成新幂等键，REST/WS 状态也尚无防乱序比较；
本批服务端同键重放保护不等于已完成断网恢复或跨设备端到端幂等。
通用文件下载仍需对象级授权；不要用该入口托管私有正文。
旧子实体编辑尚未具备全面的“已发布版本冻结/修改后审批失效”；现有初始私本字段与
真人 `is_murderer` 提示也不能直接用于不自知凶手或分阶段记忆剧本。不能据此宣布《孽岛疑云》已可完整上线。

## 验证

从仓库根目录执行：

```sh
backend/.venv/bin/python backend/scripts/test_fusion_security.py
```

该入口禁用 dotenv 和外部网络，绕过旧全局 conftest 的生产应用初始化。
使用虚构数据、SQLite 内存数据库、mock 认证/模型；传输测试执行真实处理函数体，跳过应用启动与装饰器。
不连接当前 PostgreSQL，不修改 `.env`，不重启 Docker。

前端（在 `frontend` 目录，使用已有依赖）：

```sh
node --test tests/fusion-evidence-panel.test.cjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

以上不等于浏览器整局、真实模型质量、语音延迟或 PostgreSQL 并发验收。
现有 SQLAlchemy/Pydantic/datetime 弃用告警仍待后续清理。本批没有重新构建部署容器；
运行中的旧容器不会因此自动更新，部署前仍需确认数据库备份和工作目录。
