# M3 每轮调查与阅读工作区（2026-09-09）

目标：阶段推进常驻顶部右侧，主持人入口易发现；玩家一次选多个调查地点，其余角色自动接手剩余调查点；左侧按轮保存已获资料；可选阶段复盘；底部返回主界面；其他角色只需一次批量提交。

用户已明确选择“AI 自动选择地点并用完本轮剩余调查点”。此次将其实现为单人版自动搜证规则：先按玩家选中顺序执行当前合法且合计可负担的地点，再由其他角色轮换，按剧本已定义地点顺序选择合法可付地点。选址角色不是亲自到场搜证者：原场景由吉叔查看并公开结果。无需模型投票或新增模型调用；角色对白仍走原有受限议题。不能把程序自动搜证称为模型独立推理。无合法可付地点时如实保留余额，不跳过前置条件。

完成标准：批量命令原子、幂等，拒绝重复/未来/超预算选点且不产生部分扣点；每次实际调查可追溯地点、选址角色、实际新获卡和消耗；不自动跨阶段、不额外公开私密卡。旧事件/绑定/失败收据保持可重放。每轮材料记录由服务器按玩家首次可见阶段投影；复盘只整理已可读证据、角色说法和本人记录，保留归属，不生成新事实或答案。手机收起侧栏，固定栏和输入框不遮挡内容。

范围：guided 命令/schema/replay、只读每轮投影、前端游戏栏/调查选择/复盘/批量封卷、PRD 与验证清单。保留现有收藏及手记存储键。无数据库迁移、原本事实改写、LiteLLM/TTS 接入或 M4。

验证：专用禁网 backend/scripts/test_fusion_security.py；预检及16项预检自测；前端组件/类型/lint；隔离生产构建；独立只读审查；本机新隔离验收局双轮批量搜证与刷新/重复请求；旧数据库逐行摘要核对；桌面与390px界面检查。后端通过白名单同步私有 GitHub 新版本。
