# M3 对话逻辑修正（2026-09-09）

## 行为

1. 公开发言直接保存；选择角色回应时，自动使用当前阶段最新一条真人发言。显示原句供核对，不再提供历史发言下拉。最新发言不具备回应资格时禁用，不悄悄改回旧问题。未发送草稿需先发送。
2. 已经发出的待定请求继续以原角色、问题、版本及幂等键核对，不能因新发言改写原请求。
3. 单独对话仍走双方可见的通话和上下文，角色直接点选；换对象需结束当前对话。旧局自然输入保留，已适配有限议题的局使用当前角色可用题目。
4. 公开草稿或私人疑问可匹配当前已开放的议题。展示题目原句及角色，点选后再次确认发送。未知、多义或没有可用题目时提示补充信息/手动选择，不自动替玩家选角，不把原始疑问直接送进有限议题模型。
5. “我是谁”“他是谁”等独立歧义问题先澄清；明确“你是谁”允许向所选角色询问。引用和长句不因出现同样几个字被简单当成独立问句。
6. 对已识别的越权、外部任务及现实危险操作请求，服务器在模型准备/费用预占前拒绝；剧本对爆炸物、药物等事实讨论不因名词本身被拒绝。已保存结果和旧待定请求不重跑新规则。

## 边界

匹配采用当前授权题目字词重合推荐与确认，不能称为通用语义理解。旧局/其他真人角色没有对应有限议题目录时，继续使用原有获准材料和范围检查，不套用唐小姐目录。有限拒绝规则不能覆盖全部敏感或无关改写；AI回答仍保留原有语义验收限制。没有增加路由模型、供应商、自动选角或自动全员发言。

## 验收步骤

1. 刷新原局，公开发送一句清楚的问题，直接点选角色并请其回应；应显示刚发送的原句，没有历史发言下拉框。
2. 再发第二句，回应目标应自动变成第二句；刷新也应保持。若存在未完成请求，先核对原请求。
3. 输入“我是谁”，应提示明确是核对本人身份还是请对方介绍；改为具体人物/事件后继续。
4. 已适配议题的局输入当前疑点，应出现匹配题目。点选只预览，点击“发送所选问题”才发送；改写问题或切换对象后，不能沿用旧选择。
5. 切到单独对话，直接点选角色，查看双方记录；公开草稿不进入私聊。
